# Password Reset and Account Access

Use these steps for forgotten passwords, locked accounts, and login problems.

1. Confirm the user's identity before resetting credentials.
2. Ask the user to verify that Caps Lock is disabled.
3. Confirm that the correct username or email address is being used.
4. Use the organization's approved password reset process.
5. Create a strong temporary password if required by policy.
6. Require the user to change the temporary password after logging in.
7. If the account is locked, unlock it after identity verification.
8. Check whether multi-factor authentication is preventing access.
9. Confirm that the user can successfully sign in after the reset.
10. Escalate the issue if account permissions or directory services appear incorrect.

Never request or store the user's current password in the support ticket.
