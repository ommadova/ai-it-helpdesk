# Security Incident Response

Use these guidelines for suspicious emails, malware, ransomware, compromised accounts, or possible security breaches.

1. Tell the user not to click suspicious links or open suspicious attachments.
2. If malware or ransomware is suspected, disconnect the affected device from the network.
3. Do not delete suspicious emails before the security team has reviewed them.
4. Collect basic information about what happened and when it occurred.
5. Record any suspicious sender address, website, file name, or error message.
6. If an account may be compromised, reset the password using the approved process.
7. Review whether multi-factor authentication is enabled.
8. Report phishing messages through the organization's approved security reporting process.
9. Escalate confirmed or suspected security incidents immediately.
10. Do not attempt advanced malware removal unless authorized by the security team.

Security breaches, ransomware, malware infections, and compromised accounts should normally be treated as high-priority incidents.
