# VPN Troubleshooting

Use these steps when a user cannot connect to the company VPN.

1. Confirm that the user's normal internet connection works.
2. Verify that the correct VPN server or profile is selected.
3. Confirm that the user's username and password are correct.
4. Check whether multi-factor authentication was completed.
5. Disconnect from the VPN and reconnect.
6. Restart the VPN application.
7. Restart the user's computer.
8. Verify that the VPN client is up to date.
9. Check whether a firewall or security application is blocking the VPN connection.
10. Test whether other employees are experiencing the same VPN problem.

If multiple users cannot connect, investigate a possible VPN server or network outage.
