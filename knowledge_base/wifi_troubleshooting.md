# Wi-Fi Troubleshooting

Use these steps when a user cannot connect to Wi-Fi.

1. Confirm that Wi-Fi is enabled on the device.
2. Verify that the user is connecting to the correct wireless network.
3. Turn Wi-Fi off and back on.
4. Forget the wireless network and reconnect using the correct password.
5. Restart the computer or mobile device.
6. Restart the router or wireless access point if multiple users are affected.
7. Check whether other devices can connect to the same network.
8. Run the operating system's network troubleshooter.
9. Verify that the device received a valid IP address.
10. If the problem continues, escalate the ticket to the network support team.

For office-wide outages, treat the issue as higher priority because multiple users may be affected.
