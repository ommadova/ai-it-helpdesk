# Printer Troubleshooting

Use these steps when a printer is offline, not responding, or not printing.

1. Verify that the printer is powered on.
2. Check for paper jams or low paper.
3. Check ink or toner levels.
4. Confirm that the computer is connected to the correct printer.
5. Make sure the printer is not set to offline mode.
6. Clear any stuck jobs from the print queue.
7. Restart the printer.
8. Restart the user's computer if necessary.
9. For network printers, verify that the printer is connected to the network.
10. Reinstall or update the printer driver if the issue continues.

If several users cannot use the same network printer, escalate the issue for network or printer-server investigation.
