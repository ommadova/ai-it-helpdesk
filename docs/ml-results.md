# Ticket Classification Results

## Baseline Model

Dataset size: 30 tickets

Model:
TF-IDF + Logistic Regression

Accuracy:
33%

The first model had low accuracy because the training dataset was very small.

## Improved Model

Dataset size: 100 tickets

Model:
TF-IDF + Logistic Regression

Accuracy:
73.3%

Macro Precision:
80%

Macro Recall:
73%

73%

Increasing the number of labeled training examples significantly improved classification performance.
