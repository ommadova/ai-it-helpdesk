# Priority Prediction

The current priority system uses rule-based text matching.

## High
Examples:
- server down
- entire office network down
- ransomware
- security breach
- hacked account
- all users affected

## Medium
Examples:
- password reset
- account locked
- VPN problem
- access denied
- software crash

## Low
Examples:
- printer issue
- mouse issue
- minor hardware issue
- general support request

The priority rules can later be replaced or compared with a machine learning model.
